เครื่องหมายทั่วไป

กดสัญลักษณ์ที่ต้องการ ระบบจะเพิ่มลงในช่องข้อความและคัดลอกให้ทันที คุณจึงกดต่อกันหลายตัวแล้ววางทีเดียวได้

เลือกใช้อย่างไร

สัญลักษณ์เหมาะกับการตกแต่งชื่อโปรไฟล์ bio หัวข้อ และเส้นคั่นในแคปชัน ลองจับคู่ ★ กับข้อความสั้นๆ หรือใช้ ➤ นำหน้ารายการ ใช้พอดีๆ จะอ่านง่ายกว่าใส่เยอะ

ข้อควรระวัง

บางสัญลักษณ์แสดงต่างกันตามอุปกรณ์ และโปรแกรมอ่านหน้าจอจะอ่านชื่อสัญลักษณ์ออกมาทุกตัว ถ้าใช้มากเกินไปอาจรบกวนผู้ใช้ที่ใช้โปรแกรมเหล่านี้

ต้องการกรอบสำเร็จรูป ลองเครื่องมือตกแต่งข้อความหรือดูตัวอักษรหน้าๆ

คำถามที่พบบ่อย

ใช้สัญลักษณ์พิเศษได้ที่ไหนบ้าง

ใช้ได้กับแอปส่วนใหญ่ที่รองรับ Unicode เช่น Instagram, Facebook, LINE, TikTok และ Discord

ทำไมบางสัญลักษณ์แสดงเป็นกล่องสี่เหลี่ยม

อุปกรณ์หรือฟอนต์ของผู้รับอาจไม่มีสัญลักษณ์นั้น ลองเลือกสัญลักษณ์อื่นที่ใกล้เคียงกัน

เครื่องมือที่เกี่ยวข้อง

  • ตัวอักษรวงกลมพิมพ์ข้อความแล้วแปลงเป็นตัวอักษรวงกลม วงเล็บ และสี่เหลี่ยม คัดลอกไปใช้ใน IG, Facebook, LINE ได้ฟรี
  • ตัวหนา ตัวเอียงแปลงข้อความเป็นตัวหนา ตัวเอียง และตัวหนาเอียง ใช้ได้ในแอปที่ไม่มีปุ่มจัดรูปแบบ เช่น Instagram, Facebook, LINE คัดลอกวางได้ฟรี
  • ตัวอักษรขีดฆ่าแปลงข้อความเป็นตัวอักษรขีดฆ่า ขีดทับ และขีดเฉียง ใช้ได้กับทั้งภาษาไทยและอังกฤษ คัดลอกไปวางใน IG, Facebook, LINE ได้ฟรี
  • ตัวอักษรขีดเส้นใต้แปลงข้อความเป็นตัวอักษรขีดเส้นใต้ เส้นใต้สองชั้น เส้นใต้หยัก และเส้นบน ใช้ได้กับภาษาไทยและอังกฤษ คัดลอกวางได้ฟรี

นักพัฒนาเว็บและนักเขียนเนื้อหาเครื่องมือดิจิทัล

กานดามีประสบการณ์กว่า 8 ปีด้านการพัฒนาเว็บไซต์ ระบบข้อความ Unicode และการปรับแต่งเว็บสำหรับผู้ใช้ภาษาไทย เธอสนใจทำให้เครื่องมือออนไลน์ใช้งานง่าย เข้าถึงได้ และไม่เก็บข้อมูลของผู้ใช้
