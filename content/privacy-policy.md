## ข้อความที่คุณพิมพ์

เครื่องมือทั้งหมดทำงานในเบราว์เซอร์ของคุณ ข้อความที่พิมพ์จะไม่ถูกส่งหรือบันทึกที่เซิร์ฟเวอร์ของเรา

## ข้อมูลการใช้งาน

เว็บไซต์ตั้งอยู่บน GitHub Pages ซึ่งอาจบันทึกข้อมูลทางเทคนิคพื้นฐาน เช่น IP address ตามนโยบายของ GitHub หากเราเพิ่มเครื่องมือวิเคราะห์หรือโฆษณาในอนาคต จะอัปเดตหน้านี้และแจ้งการใช้คุกกี้อย่างชัดเจน
